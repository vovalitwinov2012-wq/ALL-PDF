# ALL PDF — 19 бесплатных инструментов для PDF

🚀 **Открыть приложение:** https://t.me/allpdfeditors_bot/allpdf

Объединяйте, делите, сжимайте, конвертируйте, распознавайте сканы, подписывайте и шифруйте — прямо в браузере или в Telegram Mini App. Без регистрации и подписок.

🔒 **Файлы обрабатываются только на вашем устройстве** и никуда не загружаются.

## Как пользоваться

1. Откройте приложение по ссылке выше.
2. Выберите инструмент на главной.
3. Перетащите файл, нажмите кнопку, скачайте результат.

Каждый инструмент подсказывает следующий шаг прямо на экране: сначала «Проверить», потом «Выполнить», результат — всегда с кнопкой «Скачать».

## Что умеет

**Собрать и разобрать**
• Объединение PDF и фото (порядок, страницы на файл)
• Разделение: извлечь, удалить, повернуть, нарезать в ZIP — с предпросмотром
• Органайзер страниц: миниатюры, порядок, поворот, удаление
• Фото → PDF (есть камера)

**Читать и искать**
• Просмотр: лента страниц, зум 50–300%, поиск с подсветкой
• PDF → текст (TXT) и PDF → картинки (JPG/PNG, ZIP)
• OCR сканов: русский и английский, PDF с поиском
• Сравнение двух версий рядом, с процентом совпадения
• Таблицы → CSV для Excel

**Менять и подписывать**
• Редактор: штампы (хоть по-русски!), водяные знаки, номера страниц, нумерация Бейтса
• Фигуры и пометки: стрелки, карандаш, маркер, текст, зачернение
• Обрезка полей тянущейся рамкой
• Подпись: нарисуйте и расставьте по местам, библиотека хранится в браузере
• Формы: заполнить и зафиксировать

**Чинить и защищать**
• Починка битых PDF
• Пароль AES-128/256, снятие пароля, очистка метаданных
• Извлечение встроенных картинок в оригинальном качестве
• Сжатие с ползунком силы 1–100%: фото ужмутся, текст останется текстом

## Полезно знать

• **Лимит:** файлы до 50 МБ — этого хватает почти всегда.
• **Пустой текст?** Значит, у вас скан без текстового слоя — поможет инструмент «OCR».
• **Офлайн:** после первого визита приложение работает без интернета (установите его на главный экран — это PWA).
• **Языки:** русский и английский, переключаются в шапке.

## Частые вопросы

**Куда загружаются мои файлы?**
Никуда. Вся обработка идёт в вашем браузере.

**Почему фрагмент «СОГЛАСОВАНО» встал не туда?**
В Редакторе и Подписи сначала откройте документ в окне и тапните нужное место — штамп встанет ровно туда.

**Файл стал больше после сжатия?**
Так и скажем честно — и предложим оставить оригинал. Слайдером силы можно найти баланс.

**Что если в файле больше 30 страниц?**
Предпросмотр показывает первые 30, обработка идёт по всему документу — приложение предупредит, где это важно.
