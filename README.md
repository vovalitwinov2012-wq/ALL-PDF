# ALL PDF

Бесплатный локальный PWA-комбайн для работы с PDF. 100% обработка в браузере — файлы не покидают устройство. Без регистрации, подписок и серверов.

**19 инструментов:** просмотр, объединение PDF+фото (порядок + страницы на файл), разделение (извлечь/удалить/повернуть/постранично в ZIP/каждые N), органайзер страниц (миниатюры, drag&drop), сжатие, фото→PDF (камера, EXIF-поворот), PDF→картинки (ZIP), PDF→текст, OCR (текст + searchable PDF, рус/анг), извлечение картинок, редактор (текст с позицией, штампы, Бейтс, watermark, номера, метаданные), фигуры и пометки, обрезка полей, починка PDF, сравнение версий, таблицы в CSV (beta), заполнение форм, подпись рисунком, AES-шифрование и снятие пароля, очистка метаданных.

## Запуск

```bash
npm install
npm run dev          # разработка + автооткрытие браузера
npm test             # 27 unit-тестов ядра (ranges, pdfOps, pages, diff, tables, exif)
npm run build:pages  # сборка для GitHub Pages (dist/ + 404.html + .nojekyll)
node scripts/gen-icons.mjs  # перегенерировать PWA-иконки (без зависимостей)
node scripts/qa-locales.mjs # сверка ключей i18n с кодом
```

Двойной клик по `start.bat` делает то же самое, что `npm run dev -- --open`, — для тех, кто не любит терминал.

## Деплой на GitHub Pages

1. Settings → Pages → Source: **GitHub Actions**.
2. Push в `main` — workflow `.github/workflows/pages.yml` соберет и опубликует.
3. URL: `https://<user>.github.io/ALL-PDF/#/`

`base: '/ALL-PDF/'` + `HashRouter` уже настроены. PWA: `manifest` + `sw.js` генерируются автоматически, OCR-модели кэшируются после первой загрузки.

## Архитектура

- `src/features/pdf-core/` — чистые функции pdf-lib (merge/split/compress/stamp/metadata/sanitize/flatten/sign) + тесты.
- `src/pages/tools/*` — 12 инструментов, каждый: Dropzone → настройки → результат.
- `src/i18n/locales/{ru,en}.json` — все строки, RU по умолчанию.
- `src/components/*` — Dropzone, FileList, ResultCard, Layout.

## Честные ограничения

- HEIC/TIFF: не встраиваются локально — честная ошибка с подсказкой. Битые картинки отличаем от HEIC по сигнатуре байтов.
- EXIF-поворот фото исправляется автоматически (только ориентации 3/6/8, зеркальные — редкость).
- OCR: модели ~15–30 МБ докачиваются при первом запуске (нужен интернет), дальше кэшируются service worker'ом; за раз — до 10 файлов и 20 изображений.
- Предпросмотр: Viewer — до 20 страниц, PDF→картинки — до 50, органайзер — до 100 миниатюр.
- Извлечение картинок и таблицы — best-effort эвристики: CMYK/Indexed-картинки и сложная верстка могут пропускаться, интерфейс предупреждает.
- Визуальное зачернение — не forensic-redaction: текст под черным прямоугольником остается в файле.
- Лимиты: 50 МБ/файл; за раз: до 20 PDF, до 50 фото — guard в UI на каждом инструменте.
- Результат всегда сбрасывается при смене настроек/файлов, входы блокируются на время обработки — скачать «несвежий» файл невозможно.

## FAQ

- **Куда загружаются мои файлы?** Никуда. Вся обработка — pdf-lib, pdf.js и Tesseract в вашем браузере.
- **Почему PDF→текст пустой?** Это скан без текстового слоя — используйте «OCR: скан → текст».
- **Можно ли установить как приложение?** Да, это PWA: в Chrome/Edge — «Установить», на телефоне — «На экран Домой». Иконки PNG генерируются скриптом выше.
- **Пароль настоящий?** Да: AES-128/256 через QPDF (WASM), плюс снятие пароля. Движок грузится лениво при открытии Защиты.
