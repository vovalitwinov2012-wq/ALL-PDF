# ALL PDF

Бесплатный локальный PWA-комбайн для работы с PDF. 100% обработка в браузере — файлы не покидают устройство. Без регистрации, подписок и серверов.

**12 инструментов:** просмотр, объединение (порядок + страницы на файл), разделение/поворот/удаление страниц, сжатие, фото→PDF (включая съемку с камеры), PDF→картинки (ZIP), PDF→текст, OCR сканов (рус/анг), редактор (текст с позицией, водяной знак, номера страниц, метаданные), формы, подпись рисунком, защита и очистка метаданных.

## Запуск

```bash
npm install
npm run dev          # разработка + автооткрытие браузера
npm test             # тесты
npm run build:pages  # сборка для GitHub Pages (dist/ + 404.html + .nojekyll)
```

Двойной клик по `start.bat` делает то же самое, что `npm run dev -- --open`, — для тех, кто не любит терминал.

## Деплой на GitHub Pages

1. Settings → Pages → Source: **GitHub Actions**.
2. Push в `main` — workflow `.github/workflows/pages.yml` соберет и опубликует.
3. URL: `https://<user>.github.io/ALL-PDF/#/`

`base: '/ALL-PDF/'` + `HashRouter` уже настроены. PWA: `manifest` + `sw.js` генерируются автоматически, OCR-модели кэшируются после первой загрузки.

## Архитектура

- `src/features/pdf-core/` — чистые функции pdf-lib (merge/split/compress/stamp/metadata/sanitize/flatten/sign) + тесты.
- `src/pages/tools/*` — 12 инструментов, каждый: Dropzone → настройки → результат.
- `src/i18n/locales/{ru,en}.json` — все строки, RU по умолчанию.
- `src/components/*` — Dropzone, FileList, ResultCard, Layout.

## Честные ограничения

- Пароль: pdf-lib не делает настоящее AES-шифрование — интерфейс прямо предупреждает, выполняется пометка + очистка метаданных.
- HEIC/TIFF: не встраиваются локально — честная ошибка с подсказкой.
- OCR: модели ~15–30 МБ докачиваются при первом запуске (нужен интернет), страницы сверх 10 обрезаются с предупреждением.
- Лимиты: 50 МБ/файл, 20 файлов — guard в UI.
