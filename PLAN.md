# План доработок ALL PDF — выполнен полностью ✅

## QA-заход: 9 багов найдены и исправлены ✅

Команда тестировщиков (tsc + 40 unit-тестов + E2E 4/4 + E2E-mobile 24/24 +
живые браузерные прогоны) нашла и починила:

- [x] **Кириллица**: штампы/фигуры/водяные/Бейтс падали с `WinAnsi cannot encode`
      (все 5 пресетов были мёртвыми). Новый `lib/fonts.ts`: DejaVu Sans через
      `@pdf-lib/fontkit`, сабсет (в файл едут только нужные глифы), латиница —
      по-прежнему быстрым Helvetica. Шрифты лежат в `assets/fonts`, прекэшируются
      PWA. Тесты: `fonts.test.ts` + кириллические кейсы в `pages/pdfOps.test.ts`.
- [x] **Сжатие**: общий XObject пережимался по разу на страницу (свой же выход
      — доказано прогоном: входы `[480000, 8000, 8000]`). Дедуп по ref в
      `recompressPdf` + тест «shared XObject once».
- [x] **Обрезка** больше не игнорирует страницы за капой: `run()`/`toAll()` идут
      по всем страницам (невидимые — с полями по умолчанию), висит честное
      `crop.cappedNote`. Подпись и Редактор тоже предупреждают (`cappedNote`).
- [x] **Редактор**: пустое поле страницы больше не штампует весь документ —
      теперь понятная ошибка `badPages`.
- [x] **Просмотр**: защита от гонки `openSeq` — удалённый во время загрузки файл
      не воскресает призраком с самооткрывающимся окном.
- [x] **Сравнение**: `truncated` только если страниц реально больше 20 (было
      ложное предупреждение ровно на 20).
- [x] **Редактор**: одна общая строка ошибки вместо трёх одинаковых.
- [x] **Подпись**: библиотека переживает перезагрузку (localStorage, мелкие PNG,
      лимиты 20 шт / 200 КБ), удаление отзывает object URL.
- [x] **Сравнение**: один проход рендера, OCR только страницам без текста
      (было двойное время на сканах).
- [x] Косметика: Escape в поиске оверлея не закрывает окно; скролл к первому
      совпадению через эффект (без эвристики 50 мс); превью «Повернуть» не
      вылезает из рамки; `saveSetting` вне апдейтера; детект повёрнутых страниц
      + честные `rotatedNote` в Обрезке/Подписи.
- [x] Живой QA-прогон после фиксов: кириллический штамп применяется,
      пустая страница — ошибка, truncated на 20 стр. нет, все три cappedNote
      видны, библиотека жива после reload, Escape/поиск в оверлее корректны,
      JS-ошибок ноль.
